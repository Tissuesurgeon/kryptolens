# Judge walkthrough

1. Open the landing page. Read **Tell KryptoLens what matters.** / **Give it a job. It keeps watch for you.**
2. Submit: “When BTC drops by 2%, check the top 100 coins and rank their declines.”
3. Sign up with a new email.
4. Confirm the Agent job, event-triggered routine, and workflow steps.
5. Create the routine. Status becomes Watching (or Working while a run is in flight).
6. Check now. Results come from live CMC (or an honest error if the key is missing).
7. Say “Only show coins that dropped more than BTC.” Confirm the next version if the agent proposes it.
8. Optional: Settings → Telegram. Inbound uses the same conversation as the web.

No operator login. No seeded market data.
