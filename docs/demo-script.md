# Demo script

1. Open the landing page. Read the tagline. Optionally preview a compile. Click **Enter Demo**.
2. If you previewed an intent, the Lens is created after auth. Otherwise compile from **Ask KryptoLens…** or a template. Nothing is pre-seeded.
3. Show **You asked** / **KryptoLens assumed**, then the policy card.
4. Click **Activate**, then **Run now**. The request returns a `run_id`; the scan stage updates from the database.
5. If `CMC_API_KEY` is set, live listings and Fear & Greed are fetched. Point at workspace status: Watching / Checking / Scan complete / Degraded / Paused.
6. Open an Event Receipt. Walk the five blocks. Click **View API evidence** (dialog).
7. Open Settings: Connect / test / disconnect Telegram if the bot token is present.
8. Optional: ask KryptoLens to revise the lens. Show the policy diff. Apply v2. The earlier receipt still cites Lens v1.

Do not claim real-time watching. Do not invent ticks. If the market is quiet, say so and keep the thresholds honest. Still use live quotes.
