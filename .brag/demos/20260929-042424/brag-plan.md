# Brag Plan: KryptoLens

## What is this app?
A conversational crypto analyst: create an Analyst (stored as a Lens), ask a question, and it researches live CoinMarketCap data in the same conversation.

## The angle
polished

## Hook
Voice: direct, specific, Tell → Clarify → Watch → Act → Return. Never claims real-time continuous observation; monitoring is periodic. Never calls itself a demo. Never invents market numbers. Quiet markets and missing data (not treated as zero) are valid outcomes. User-unnamed coins are not filled in as Bitcoin.

## Key moments (the middle)
- Show the real KryptoLens interface — Lens workspace.
- Sign up or log in → Create a Lens from a natural-language intent or a draft → Open the workspace conversation → Send a question; understanding and planner compile a task → Runtime fetches CMC data, verifies, and replies in the same thread
- Authenticated users create a Lens and converse on lens_detail; AgentService and ConversationService compile and run work, rendering workspace/lens.html.
